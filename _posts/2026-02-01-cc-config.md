## 前言

AAAI参会的过程中有幸跟着Dizhan师兄学到了很多，其中一项正是对于vibe coding（具体而言正是CC）的技巧探讨。在从古法编程转为付费的cursor后笔者感受到的变化不亚于原始人掌握了工具，所以对于相关的“奇技淫巧”相当痴迷，这里简单记录下CC配置的过程以及常见的问题。

### Cli配置

CC-Switch安装：

[farion1231/cc-switch: A cross-platform desktop All-in-One assistant tool for Claude Code, Codex, OpenCode & Gemini CLI.](https://github.com/farion1231/cc-switch)

安装后在图形化界面可以配置自己的Base_url, API_Key等

**缺点**：没有对Openai格式的api进行处理，相当多的第三方API无法直接使用

9-router

支持了第三方API，支持了相对便捷的Antigravity反代等

缺点：相当多的功能vibe coding实现，莫名其妙的小bug

### VSCode配置

本地

“Disable Login Prompt”设置为打开

settings.json添加(注意是AUTH_TOKEN而不是API_KEY)：

```
    "claudeCode.environmentVariables": [
        {
            "name": "ANTHROPIC_BASE_URL",
            "value": "https://example.com/v1"
        },
        {
            "name": "ANTHROPIC_AUTH_TOKEN",
            "value": "sk-example"
        },
    ],
```

ssh服务器

“Disable Login Prompt”设置为打开

settings.json添加：

```
    "claudeCode.environmentVariables": [
        {
            "name": "HTTP_PROXY",
            "value": "http://example.com:7890"
        },
        {
            "name": "HTTPS_PROXY",
            "value": "http://example.com:7890"
        },   
        {
            "name": "ANTHROPIC_BASE_URL",
            "value": "https://example.com/v1"
        },
        {
            "name": "ANTHROPIC_AUTH_TOKEN",
            "value": "sk-example"
        },
    ],
```
