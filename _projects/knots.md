Knots focuses on semantic parsing for aviation NOTAMs, pairing an expert-annotated dataset with prompt optimization strategies designed for deeper structured understanding.

For the site, this project acts as a realistic example card and detail page, so the list page and the per-project reading experience both match the newer visual language.

The code repository is available at [GitHub](https://github.com/Estrellajer/Knots).
